# Bedrock

Bedrock is an open-source, local-first foundation for persistent, secure, and verifiable AI agent execution.

Run Claude Code, Codex, Gemini, OpenCode, GPT-OSS, and Nemotron side by side in real terminals with human-in-the-loop approval gates, shared context, and continuous supervision.

## Quick Start

```bash
# Install dependencies
npm install --legacy-peer-deps

# Start backend daemon and web interface
npm run dev

# Or run tests
npm test
```
