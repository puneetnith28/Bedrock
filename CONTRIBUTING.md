# Contributing to Bedrock

Thank you for contributing to Bedrock!

## Branching Conventions
- `feat/<feature-name>`: New capabilities or provider integrations.
- `fix/<bug-name>`: Bug fixes and error handling improvements.
- `chore/<task-name>`: Build, release, or refactoring tasks.

## Conventional Commits
All commits must follow the [Conventional Commits](https://www.conventionalcommits.org/) specification:
`<type>(<scope>): <short summary>`

Types: `feat`, `fix`, `refactor`, `perf`, `test`, `docs`, `chore`, `ci`, `build`, `security`.
